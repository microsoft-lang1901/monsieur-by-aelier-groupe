## Repository Map

- **Application and user interface:** `app/`, `src/`
- **Data and persistence:** `data/`, `supabase/`
- **Tests and release evidence:** `tests/`
- **Documentation:** `docs/`

## Runtime and Tooling Evidence

- Detected root frameworks: react, react-native, expo, typescript, @supabase/supabase-js
- Tracked manifests: package.json
- Root validation scripts: start, typecheck, test, verify

## System Boundary

The canonical catalogue and production environment evidence remain required for a real release.

The repository tree and executable manifests are authoritative when they differ from roadmap or concept documents. External providers, credentials, infrastructure, and approvals are not assumed to exist from configuration files alone.
